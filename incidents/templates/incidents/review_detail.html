{% extends "base.html" %} {% load i18n ui %} {% load workflow_tags %} {% load accounts_tags %} {% comment %} The A.5.27 learning record, and the bridge to ISO/IEC 27001 clause 10.2. The review has no title of its own : exactly one exists per incident, so it is identified by its reference and by the incident it draws its lessons from. Two halves, and the page keeps them apart on purpose: - The **analysis** : the determined root cause *with the method used to determine it* (a cause with no named technique is a plausible guess), the detection gap, and the controls that were in place and did not hold. - The **consequences** : the outward links that make an incident change something. Every target is an existing register - the same nonconformity an audit raises, the same action-plan lifecycle, the same risk and vulnerability registers, the same management-review output. Nothing here is a parallel table. The effectiveness verdict is the clause 10.2 d) / f) record and gets a card of its own, because a closed action plan proves the action was implemented and never that it worked.
